# Update 2.0: Euyskuyyy Polishing Package kicked in, yo!
Chimmy Collect Crystal on Unity by EUYSKUYYY
Solo developed by Nathanael Noah Purwoadi

Chimmy Collect Crystal is a game where you collect crystals and avoiding dlying cats.
Based on my old Scratch game: https://scratch.mit.edu/projects/855597601/ , now remade in Unity.

# Key Mechanics
* Collect randomly spawned crystals, each has different score and frequency
* Crystals now can disappear when not collected fast enough
* Avoid increasingly fast cats that damage you
* New mode: CCC Advanced. With faster spawn and lifetime more HP, and buff/debuff items.
* Option to activate One Hit KO mode, because the old Scratch version has it, but got replaced by HP system.
* Leaderboard for all 4 modes (2 modes, OHKO on/off)
